# Community Cleanups

Event creation and scheduling: organizers can create clean-up events with title, description, date/time, location, and volunteer capacity

Volunteer registration: users can browse upcoming events and sign up to participate, with the ability to cancel their registration

Attendance tracking: organizers can mark volunteers as attended or absent for each event

Progress tracking and reporting: volunteers and organizers can log waste collected (weight/bags) and upload before/after photos for each event

Location mapping: display clean-up event sites on an interactive map with location pins and event details

Leaderboard and gamification: rank volunteers by total events attended and waste collected, with badges for milestones

Admin dashboard: manage events, view volunteer lists, track overall statistics, and generate summary reports

Notification and reminders: send email reminders to registered volunteers before upcoming clean-up. also include database and everything 

**live app: https://civic-track-murex.vercel.app
